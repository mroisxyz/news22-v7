A news-image mosaic for the `news-image-20261122` bounty: 36 dated stories distilled into 3 lead scenes, 12 cards, and a three-column digest with a built-in date check.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.png` is copied (defaults to `/output`).
